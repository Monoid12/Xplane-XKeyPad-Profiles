REQUIREMENTS
  Required: X-Plane 12, Stream Deck software (7.1 or later), X-KeyPad (registered), FlyWithLua NG+
  Optional: X-Camera, BetterPushback, SimLoad Manager, AviTab, xPilot – the installer detects them
            and leaves out the keys of missing plugins; Discord plugin for Stream Deck;
            AeroACARS (German Sky Group)

INSTALLATION
1. Start the Stream Deck software once with the devices connected.
2. Quit X-Plane.
3. Put the folder "P_Profile" into "X-Plane 12/Resources/plugins".
4. Start the installer in the folder:
   macOS:   Installieren_macOS.command  (right-click › Open)
   Windows: Installieren_Windows.bat    (double-click)
5. Choose the language, check profiles, plugins and extras in the window, then "Install".
6. In the Stream Deck software choose the aircraft's profile (e.g. P_A320);
   afterwards NEXT/PREV on the XL switches both devices together.

Running the installer again adds further profiles. The installer backs up every file it
replaces to Documents/P_Profile_Sicherung_<date>; your own configurations are also kept
permanently as originals.

RESTORE
Start Wiederherstellen_macOS.command or Wiederherstellen_Windows.bat (X-Plane closed) and
choose the original state before the P_ Profiles or a backup (handbook chapter 3.8).

UPDATES
The SkunkCrafts Updater finds the folder "P_Profile" in "Resources/plugins" by itself and keeps
it up to date. With "Automatic updates", the installer window opens by itself after every
update (handbook chapter 3.9).
