P_ Profiles for X-Plane 12 – changelog
(Deutsch: siehe CHANGELOG.txt)

Version 3.1 – 17 November 2026
  - Automatic updates: when the SkunkCrafts Updater brings the folder "P_Profile" to a new version, a
    window with your installed profiles opens by itself afterwards; you can add more, and "Install"
    installs everything (profiles, configurations, camera views, Lua scripts). While X-Plane is running
    it waits until X-Plane has been quit; "Later" asks again after 12 hours.
    For this the installer sets up an update helper on request (run the installer once by hand).
  - Installer: finds the X-Plane folder when started from "X-Plane 12/P_Profile"; detects X-Plane by its
    exact process name; waits more reliably for the Stream Deck software to quit.

Version 3.0.1 – 17 November 2026
  - Simple Ground Equipment & Services (SGES) removed: the GROUND folder and its 17 keys are gone from
    all profiles and X-KeyPad configurations; SGES is no longer a prerequisite.
  - Start page: SIMLOAD and PUSHBACK each move one place to the left.
  - FPS E175/E190/E195: the door keys now actually move the doors (before, they only switched a
    display value of the EFB). DOORS page with all six doors: DOOR L1, DOOR R1, DOOR L2,
    DOOR R2 (service door), CARGO FWD and CARGO AFT.

Version 3.0 – November 2026
  - 68 aircraft, 110 profiles (previously 29/58); no longer marked as beta.
  - New airliners: FlyJSim 737-200, Sparky 747-400, FPS 747-8, Laminar A330-300,
    FPS E175/E190/E195, X-Crafts ERJ 135/140/145/145XR/Legacy 600,
    Just Flight BAe 146-100/-200/-300, Colimata Concorde.
  - New business jets: Aerobask Falcon 8X and Phenom 300, AKD Gulfstream G550 and G650/G650ER,
    TorqueSim CitationJet 525, Laminar Citation X, Airfoillabs King Air 350 (GNS and GTN).
  - New general aviation: Just Flight C152 and PA-28R Turbo Arrow (also with REP), Airfoillabs C172 NG
    Analog/Digital, CIS Seneca II, PAE Bonanza G36 and A36 (Analog/Glass), Thranda V35B Bonanza and
    C208 Caravan (four versions), RSG DA40 NG.
  - One profile for several aircraft files with the same cockpit (ERJ, BAe 146, C208, C172 NG and others).
  - New XL pages for the G1000 (PFD/MFD), GNS 430/530 and GTN with matching Plus pages.
  - X-Camera views 1–15 for all new aircraft, checked by screenshot in the simulator.
  - NEXT/PREV circle: airliners → business jets → E-Jets/ERJ/BAe 146 → Concorde → GA → 737.
  - Additional distribution via the SkunkCrafts Updater.

Version 2.0.1 (BETA) – 9 November 2026
  - Challenger 650: Plus dials SPEED, HDG, ALT, VS/PITCH, BARO and RANGE show the selected values.
  - Challenger 650: new Plus pages DCP 1, DCP 2 and brightness (PFD/MFD, CDU 1–3/ISI);
    DCP 2 keys additionally on the XL page DCP.
  - Challenger 650: new XL pages CCP 1 and CCP 2 (whole control panel); the select keys on the EICAS page
    switch the Stream Deck + to the CCP page with the MENU and RADIO dials at the same time.
  - Challenger 650: Plus dials respond more directly (one detent = one step, no more overrun on HDG/ALT).
  - New FlyWithLua script P_CL650_Werte.lua (live values of the Challenger, preselected in the installer).

Version 2.0 (BETA) – 28 October 2026
  - 29 aircraft, 58 profiles (previously 18/36). Beta: not all functions tested.
  - New: Zibo 737-800, LevelUp 737-600/-700/-800, Felis 747-200 and 747-200F,
    Rotate MD-11 and MD-11F, DeltaWing ATR 72-600, FlyJSim Dash 8-400 (Q4XP),
    Hot Start Challenger 650 – each with X-Camera views 1–15.
  - NEXT/PREV circle: 737 → 747 → 757 → 767 → 777 → Airbus → MD-11 → ATR → Dash 8 → Challenger → 737.
  - Start page: AeroACARS tiles without gaps in row 4, CAMERA folder next to them, keys XPILOT ATC/MSG.
  - Consistent spelling of key names and title colours.
  - New installer (macOS/Windows): selectable profiles, automatic circle, add-on install with
    circle correction, optional Lua scripts, AeroACARS tiles on/off, German/English.
  - New FlyWithLua script P_ATR_Hebel.lua.
  - Handbook additionally in English.

Version 1.0 – 25 October 2026
  - First release: 18 aircraft, 36 profiles (Stream Deck XL + Stream Deck +).
  - ToLiss A319, A320neo, A321, A330-900, A340-600.
  - FlightFactor 767-200ER, -300ER, -F, -SF, 767-400ER; 757-200, -300, C-32, RF; 777-200ER, -200LR, -300ER, F.
  - Consistent design and placement, NEXT/PREV circle, camera views 1–15 in all aircraft.
  - Installer for macOS and Windows with backup and automatic device assignment.
  - FlyWithLua scripts P_B777_XKeyPad.lua (reload for FlightFactor) and P_ToLiss_Schub.lua (thrust detents).
