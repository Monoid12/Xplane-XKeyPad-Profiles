# P_ Profiles – unified Stream Deck profiles for X-Plane 12

Unified profiles for the **Elgato Stream Deck XL** and **Stream Deck +** with the X-Plane plugin
**X-KeyPad** (Stick and Rudder Studios): 68 aircraft, 110 profiles – airliners, business jets and general aviation.
Every aircraft uses the same layout: the same system group on the same key, the same camera views 1–15, and
NEXT/PREV switches both devices together from aircraft to aircraft.

**Download:** see [Releases](../../releases) (ZIP with installer for macOS and Windows and the handbook in German and English).

## Updates with the SkunkCrafts Updater
1. Unpack the ZIP and put the folder `P_Profile` directly into your X-Plane 12 main folder.
2. The SkunkCrafts Updater (4.x) finds it automatically; otherwise add the folder with “Add folder…”.
3. After an update, run the installer from the `P_Profile` folder again (X-Plane closed) – it copies the
   profiles to the Stream Deck software and the configurations into the aircraft folders.

The updater depot lives in [`depot/`](depot) and is served from
`https://raw.githubusercontent.com/Monoid12/Xplane-XKeyPad-Profiles/main/depot`.

## Requirements
X-Plane 12, X-KeyPad (registered), X-Camera, FlyWithLua NG+, BetterPushback, Simple Ground Equipment & Services,
SimLoad Manager, AviTab, xPilot – details in the handbook, chapter 2. The aircraft themselves are not included.
