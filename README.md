# P_ Profiles – Stream Deck profiles for X-Plane 12

Profiles for the **Elgato Stream Deck XL** and **Stream Deck +** with the X-Plane plugin **X-KeyPad**
(Stick and Rudder Studios): 73 aircraft, 120 profiles – airliners, business jets and general aviation.

- **Keys as in the cockpit:** on every page the keys sit where the switches are in the cockpit of that aircraft.
- **Same structure everywhere:** the same home page and system groups, camera views 1–15, and NEXT/PREV switches
  both devices together from aircraft to aircraft.
- **English or German**, installer for macOS and Windows, handbook in both languages.

**Download:** see [Releases](../../releases).

## Installation and updates
1. Unpack the ZIP and put the folder `P_Profile` into `X-Plane 12/Resources/plugins`.
2. Run the installer in the folder (X-Plane closed), choose the language and the aircraft, then “Install”.
3. Updates come via the **SkunkCrafts Updater** (4.x), which finds the folder by itself. With “Automatic updates”
   the installer window opens by itself after every update.
4. **Restore:** `Wiederherstellen_macOS.command` / `Wiederherstellen_Windows.bat` brings back your own configurations
   (original state before the P_ Profiles) or any backup the installer made.

The updater depot lives in [`depot/`](depot) and is served from
`https://raw.githubusercontent.com/Monoid12/Xplane-XKeyPad-Profiles/main/depot`.

## Requirements
- Required: X-Plane 12, Stream Deck software 7.1 or later, X-KeyPad (registered), FlyWithLua NG+
- Optional: X-Camera, BetterPushback, SimLoad Manager, AviTab, xPilot, Discord plugin – the installer detects them
  and leaves out the keys of missing plugins.

The aircraft themselves are not included. Details: handbook, chapter 2.
